# UIP-01B fixtures

**These are test fixtures, not evaluation evidence.** Public tests read them. The recorded and legacy-snapshot fixtures are views of an earlier recorded demo, not of the 2026-11-23 capture; the evaluation evidence is only the replay described in `docs/EVALUATION.md`. The derived files are digest-bound. In this export, the five older path-bearing fixtures use repository-relative paths; their manifests and expected source digests are updated to match.

Reusable fixtures for the Workbench view contracts (`contracts/workbench/v1`, contract a private planning record (not in this export) v1.0.0). Generated by `tools/uip_fixtures/build.py`; **never edited by hand** (a test fails if they differ from a fresh run).

Rules: **synthetic** fixtures contain no recorded repository names and no prototype findings. Only the two derived directories may contain recorded-case names; they are never reachable from a live analysis. Each `MANIFEST.json` lists file digests, recorded source digests, the builder hash and seed, and any value normalized for determinism (the random session id and the fixed clock). Regenerate with `PYTHONPATH=src/core:src/agents/investigator python tools/uip_fixtures/build.py` using an interpreter that can import the repository dependencies.
